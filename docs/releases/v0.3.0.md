# Takt 0.3.0

Это большое обновление интерфейса и повседневных функций плеера.

## Что нового

- отдельная настройка светлой и тёмной темы;
- цвета, прозрачность, размытие, обои и пресеты оформления;
- отдельные параметры стекла для левой панели, панели воспроизведения и меню;
- редактор расположения элементов;
- изменение ширины и сворачивание левой панели;
- настройка скорости анимаций и режима производительности;
- новое окно создания плейлиста;
- увеличенное окно выбора обложки с предпросмотром;
- недавно прослушанные и недавно добавленные треки;
- просмотр библиотеки по альбомам и исполнителям;
- таймер сна с плавным снижением громкости;
- компактный режим с возможностью закрепить окно поверх остальных;
- дополнительные кнопки избранного, таймера и визуализатора;
- фоновый столбчатый визуализатор;
- пресеты оформления и расположения с импортом и экспортом JSON.

Также исправлены лишние перестроения списка при воспроизведении, гонки при быстром переключении компактного режима и переполнение интерфейса в маленьком окне.

## Проверка

- 79 автоматических тестов;
- анализ кода без ошибок;
- проверка интерфейса в настоящем окне Linux;
- проверка таймера на настоящем аудиодвижке;
- проверка окна выбора обложки;
- проверка распаковки, установки, запуска и корректного выхода из готового архива.

## Ограничения

Готовая сборка предназначена для Linux x86_64. Android и Windows в этот выпуск не входят. Прозрачность, режим поверх окон и изменение размера зависят от оконного менеджера. В плиточном Hyprland компактный режим требует плавающего окна.
