Первый публичный выпуск Takt для Linux / First public Linux release.

## Скачать и установить / Download and install

1. Скачайте **Takt-0.2.0-linux-x86_64.tar.gz** ниже (не Source code).
2. Установите системные зависимости по [инструкции](https://github.com/an0thrguy/Takt-Player/blob/v0.2.0/docs/install-linux.md).
3. Распакуйте архив и запустите `./start.sh`. Для добавления в меню приложений: `./install.sh` (без sudo).

```bash
sha256sum --check SHA256SUMS.txt
tar -xzf Takt-0.2.0-linux-x86_64.tar.gz
cd Takt-0.2.0-linux-x86_64
./start.sh
```

Download the binary `.tar.gz` asset, install the documented runtime dependencies, extract the entire folder, and run `./start.sh`. Optional application-menu installation: `./install.sh`. Flutter is not required to run the binary.

## Возможности / Features

- Local music library, automatically refreshed folders, playlists and favorites.
- Restored queue and position without autoplay; shuffle, repeat and normal playback.
- Rounded monochrome glass interface, light/dark themes and custom accent colors.
- Frequency visualizer: filled wave or bars, sensitivity, smoothing and independent color.
- MPRIS media controls, tray playback actions, headphone-disconnect pause.
- Russian/English, smooth navigation and dialogs, working text input and playback shortcuts.
- Frameless window; drag the content heading to move a floating window.

## Совместимость / Compatibility

Linux **x86_64**, built on **Ubuntu 22.04** in GitHub Actions. Requires GTK 3, libmpv and FFmpeg; optional headphone detection requires `pactl`. Runtime dependencies are not bundled. The archive is not a universal AppImage or Flatpak. Ubuntu 22.04 is the build baseline; other distributions are not all verified. ARM, Android and Windows binaries are not included.

The release workflow runs static analysis, unit/widget tests and a native Linux interface test before publishing. Physical headphone unplugging and every desktop environment still require user testing. GNOME may require a StatusNotifier/AppIndicator extension for tray support; the application does not install extensions automatically.

## Данные / Data

Music is not uploaded. Display title/artwork edits are local. Online cover lookup is disabled by default and requires opt-in. Updating the application does not reset its separate library/settings database.
