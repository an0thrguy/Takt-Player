# Takt на Android

Первая Android-сборка рассчитана на Android 16 и ARM64. Этот вариант подходит для Poco X7 и Samsung Galaxy S24 Ultra с Android 16.

## Установка

1. Открой [релизы Takt](https://github.com/an0thrguy/Takt-Player/releases).
2. Скачай `Takt-0.3.1-android-arm64.apk` из раздела Assets.
3. Открой APK. Если телефон попросит, разреши установку приложений для браузера или файлового менеджера, через который открыл файл.
4. Установи Takt и разреши доступ к аудио и уведомлениям при первом запуске.

При первом запуске Takt найдёт одну музыкальную папку. В настройках, в разделе «Музыка на устройстве», можно добавить папку из списка найденных, в том числе Download. Через «Другая папка» можно выбрать папку вручную. Там же можно переключиться на другую добавленную папку. В библиотеку попадает музыка только из добавленных папок. Приватные папки других приложений Android не показывает. Если разрешение было отклонено, открыть его можно в Takt или через настройки телефона: Приложения - Takt - Разрешения - Музыка и аудио.

Для обновления установи новый APK поверх старого. Не удаляй Takt перед обновлением, чтобы сохранить плейлисты, избранное и оформление.

## Как пользоваться

Нажатие на трек запускает музыку. Удержание выделяет его. Три полоски открывают меню, а удержание полосок позволяет менять порядок треков.

Внизу находятся библиотека, плейлисты, избранное и настройки. Мини-плеер раскрывается нажатием на название или обложку. Громкость регулируется кнопками телефона.

При сворачивании музыка продолжает играть. Переключать треки можно из уведомления и с экрана блокировки. Если удалить Takt из недавних приложений, воспроизведение остановится. При следующем запуске очередь и позиция восстановятся на паузе.

Отключение наушников и прерывание звука звонком ставят воспроизведение на паузу. Продолжение нужно включить самостоятельно.

В режиме перемешивания порядок сохраняется до конца очереди. Кнопки назад и вперёд следуют этому порядку, новый круг перемешивается заново.

Поиск обложек в интернете выключен по умолчанию. Если включить его, Takt отправляет сервису поиска исполнителя, альбом и название трека. Переименования и выбранные обложки сохраняются только внутри плеера.

## Проверка первой версии

APK собран и подписан, автоматические проверки проходят. Предыдущую сборку пользователь проверил на Poco X7. Samsung Galaxy S24 Ultra пока не проверялся.

После установки проверь поиск музыки, звук, переключение из уведомления и сохранение позиции после удаления из недавних. Также проверь паузу при звонке и отключении наушников. Эти проверки особенно важны для первой Android-версии.

## Если музыка останавливается в фоне

Сначала проверь ограничения батареи для Takt в настройках телефона. HyperOS и One UI могут ограничивать работу фоновых приложений. На Poco обычно помогает режим без ограничений батареи. На Samsung проверь, что Takt не добавлен в список спящих приложений. Названия пунктов могут отличаться между прошивками.

## Сборка из исходников

Нужны Flutter 3.47.6, Java 17, Android SDK 36 и инструменты сборки 36.0.0. Зависимости скачиваются через Flutter и Gradle.

```bash
flutter pub get --enforce-lockfile
flutter analyze
flutter test
flutter build apk --release --target-platform android-arm64
./tool/package-android.sh
```

Перед release-сборкой создай свою подпись Android. Команда попросит пароль и данные владельца:

```bash
keytool -genkeypair -keystore takt-release.jks -alias takt -keyalg RSA -keysize 4096 -validity 10000
```

Затем создай файл `android/key.properties`:

```properties
storeFile=/absolute/path/to/your-release.jks
storePassword=your-store-password
keyPassword=your-key-password
keyAlias=your-key-alias
```

Для разработки можно использовать `flutter build apk --debug --target-platform android-arm64`. Debug-подпись отличается от подписи опубликованного APK.

Ключ и пароли не входят в репозиторий. Храни их в резервной копии: будущие обновления должны быть подписаны тем же ключом.

Воспроизведение использует libmpv. Визуализатор анализирует файл через декодеры Android. У редких форматов звук может работать, а визуализатор оставаться спокойной линией.
