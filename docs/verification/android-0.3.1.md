# Android 0.3.1 release notes

Android 16 ARM64 build details:

- signed release APK with API 36;
- arm64-v8a native libraries;
- 16 KB ZIP and ELF alignment;
- notification controls and background playback;
- portrait layout, folder selection in settings and paused queue restoration;
- artwork replacement, fixed shuffle cycles and mirrored visualizers;
- solid and bar background visualizer modes.

The source tree contains the automated Flutter tests and the commands used to build the release APK.
