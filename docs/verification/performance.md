# Измерения Linux

3 октября 2026, текущий Arch Linux / Hyprland. Это ограниченная синтетическая проверка, а не гарантия для любой библиотеки и любого устройства.

## Интерфейс: 500 индексированных песен

Flutter profile, `integration_test/performance_test.dart`, через `flutter drive`.

- Поиск → обновлённый интерфейс: 66,25 мс. Измерение начинается при обновлении TextInputClient; задержка самой системной клавиатуры исключена.
- Нажатие → первые обновлённые кадры: 49,418 мс. Аудиодвижок заменён тестовым: задержка получения настоящего звука сюда не входит.
- 71 измеренный кадр, медиана полного времени кадра 8,745 мс, 95-й процентиль 22,89 мс. Постоянные 60 кадров/с на всех действиях не подтверждены.

Первое измерение до завершения всей анимации кнопки давало около 399 мс; оно включает длительность эффекта нажатия и не считается задержкой первого отклика.

## Сканирование: 500 настоящих файлов

500 синтетических FLAC в 25 папках, Linux debug, хеширование и ffprobe. Ограниченный параллелизм: три процесса чтения метаданных, постепенное обновление списка.

- Первоначальное сканирование: 18 097 мс.
- Повторная сверка без изменений: 343 мс.
- Пересекающиеся источники не дублируют записи.
- Автоматическое добавление проверено через периодическую сверку.
- Повторное открытие файла SQLite сохранило название и плейлист.

До ограниченного параллелизма первый проход занимал 36 687 мс. Большие lossless-файлы и медленные накопители требуют отдельного измерения. Расход батареи и CPU за длительную пользовательскую сессию не измерен.
