# Проверка форматов Linux

3 октября 2026. Arch Linux, libmpv через media_kit, FFmpeg 9. Образцы созданы из собственного синтетического сигнала; по каждому проверены воспроизведение, перемотка и достижение конца файла.

| Кодек | Контейнер | Результат |
| --- | --- | --- |
| MP3 | MP3 | Пройдено |
| FLAC | FLAC | Пройдено |
| PCM s16le | WAV | Пройдено |
| PCM s16be | AIFF | Пройдено |
| AAC | ADTS / AAC | Пройдено |
| AAC | M4A | Пройдено |
| ALAC | M4A | Пройдено |
| Vorbis | Ogg | Пройдено |
| Opus | Ogg / Opus | Пройдено |
| WMAv2 | WMA / ASF | Пройдено |
| WavPack | WV | Пройдено |

Повреждённый MP3 сообщает об ошибке и прекращает воспроизведение. Отдельно проверены автоматический следующий трек, один проход, круг и повтор одного трека на настоящем аудиодвижке.

APE, Musepack, DSF/DFF, DTS, AC3 и другие расширения распознаются сканером, но реальные образцы пока не проверены. Их работа зависит от декодеров установленного libmpv/FFmpeg. Формулировка «все форматы без исключений» не подтверждена.

Сценарий: `integration_test/formats_test.dart`. Генератор: `tool/generate_fixtures.py`.
