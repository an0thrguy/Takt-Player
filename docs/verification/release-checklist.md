# Takt 0.1.0 - Linux

Область: личное приложение для Arch Linux. Android и Windows не входят в эту сборку.

| Возможность | Подтверждение |
| --- | --- |
| Автопоиск Music / XDG и ручной выбор | XDG-тест, доступный выбор папки; сценарий первого запуска реализован |
| Несколько источников, вложенные папки | 500 реальных файлов / 25 папок; пересечения без дубликатов |
| Автоматическое обновление | Добавление файла через периодическую сверку пройдено |
| Недоступный источник и перенос | Регрессии сохраняют идентичность/название; неоднозначные копии не объединяются |
| Плейлисты и личный порядок | Создание/переименование/удаление, дубликаты, отдельные настройки порядка |
| Очередь и четыре режима | Unit и native EOF-проверки; сохранение позиции с восстановлением на паузе |
| Меню/выделение/перетаскивание | Короткое нажатие открывает меню; удержание переносит всю строку; регрессия жестов |
| Название/обложка без правки тегов | Локальные изменения, копирование изображения, сохранение при переносе |
| Удаление файлов | Отмена, частичный отказ, реальный отказ прав ОС; ошибки не считаются успехом |
| Темы/языки/громкость/шкалы | Native UI-проверка обеих тем, popup громкости и волнистой линии |
| Визуализатор | RMS собственного декодированного PCM; пауза и скрытие останавливают анализ |
| Обложки по разрешению | Выключено по умолчанию; нулевые запросы, отмена клиента, поздний ответ не записывается |
| Linux-трей и выход | Проверка регистрации в D-Bus; закрытие без трея сохраняет окно; длительная проверка в platforms.md |
| Сборка и упаковка | Release bundle и tar.gz; инструкция README |

Не подтверждены: реальные APE/Musepack/DSD, поиск обложки на живом MusicBrainz/CAA, физическая SD-карта, постоянные 60 fps, CPU/батарея на реальной музыкальной библиотеке. Сетевой провайдер проверен контролируемыми HTTP-ответами; доступность внешних сервисов не гарантируется.

Никакие APK, Windows-сборки, PR или Git-коммиты не созданы. Защищённая `.git` не является доступным репозиторием; исходники сохранены в папке проекта.
