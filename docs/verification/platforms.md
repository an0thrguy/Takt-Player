# Платформенная проверка

Arch Linux / Hyprland / Wayland, установленный PipeWire и Waybar. Linux toolchain Flutter исправна. 3 октября 2026 года.

Native smoke: реальный libmpv воспроизводит файл, перематывает, ставит паузу и восстанавливается без автозапуска. Popup громкости и две темы/волнистая шкала проверены в настоящем окне.

Трей: зарегистрированный StatusNotifierItem Takt обнаружен в D-Bus; IsStatusNotifierHostRegistered=true. Закрытие скрывает окно; отсутствие трея по тесту оставляет его доступным. Настройка полного выхода проверена на границе оконного адаптера.

Длительный сценарий `integration_test/background_test.dart`: все 30 проверок воспроизведения за 900 секунд при скрытом окне прошли. Возврат окна в этом запуске выявил ошибку cnativeapi 0.3.0: Activate принимался без отправки события. Исправление сохранено в third_party/cnativeapi. После исправления отдельный 30-секундный native сценарий прошёл полностью, включая Activate и возврат окна; отчёт в tray.json. Полный 900-секундный сценарий после исправления не повторялся.

Android и Windows: вне текущей версии.
