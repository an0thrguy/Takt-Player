# Third-party notices

Takt uses Flutter and Dart, media_kit, SQLite and packages listed in pubspec.lock.
Resolved dependency license texts are included in the binary archive's `licenses` directory, alongside the Flutter SDK and native engine notices. The vendored cnativeapi/nativeapi code retains its MIT license and original notices.

The Linux archive uses the host's GTK, libmpv, FFmpeg and PulseAudio-compatible utilities. These system components are installed through the user's distribution and are not bundled in this release. Their upstream licenses remain applicable independently.

Publishing this repository does not assign an open-source license to Takt's own code. No broad reuse license has been selected by the author yet; third-party code keeps its original license.
